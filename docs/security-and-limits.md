# 万象画卷安全与运行边界

## 图片输入

- 单张参考图最大 20MB。
- 单次请求最多 14 张参考图，总计最大 64MB；自定义图片 JSON 端点最多发送 3 张，具体 Provider 或端点可能有更低上限。
- Data URL、远程 URL 和本地文件都会进行格式、大小和路径校验。
- 远程参考图仅允许 `http`/`https`，拒绝用户凭据、环回地址、私网地址、链路本地地址，并逐跳限制重定向次数。
- 配置页预览只读取插件数据目录内的普通图片文件；其他本地路径不会回显或提供下载。
- 其他插件显式传入 `refs` 时，本地路径默认也必须位于插件数据目录内；URL 和 Data URL 不受此目录规则影响，但仍会执行上述安全校验。

## 配置与密钥

- `get_config` 只返回 API Key 掩码和 `api_keys_configured` 状态，不返回密钥原文。
- 保存配置时，未修改的掩码项会保留原密钥；清空输入框才会删除对应密钥。
- 配置保存使用临时文件原子替换。运行时校验或持久化失败时，会恢复本轮运行时对象。
- `/切换人设`、`/切换链路`、`/切换模型`、预设增删改为 AstrBot 管理员命令。

## 批量与后台任务

- 副脑批量数量硬上限为 10。
- 后台任务队列最多保留 16 个任务，同时最多运行 4 个后台任务；队列满时新任务会明确失败，不会无限创建协程。
- 视频异步任务提交后，轮询沿用同一把 API Key，并受 Provider timeout 的绝对 deadline 约束。

## Web API 部署边界

`generate_image_for_plugin` 没有聊天事件上下文，因此插件本身无法推断调用用户、群组和额度。它只能作为受信任的本机插件桥接接口使用；宿主部署必须提供鉴权、CSRF/Origin 校验、请求体限制和调用方审计。不要把该路由直接暴露到公网。
